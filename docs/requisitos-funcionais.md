# Requisitos Funcionais — Portal do Cidadão

| Código | Descrição |
|--------|-----------|
| RF01 | O sistema deve permitir que o usuário visualize com mais detalhes as propostas legislativas em tramitação na Câmara Municipal. |
| RF02 | O sistema deve permitir que o usuário publique, edite ou exclua um comentário próprio sobre uma proposta legislativa. |
| RF03 | O sistema deve permitir que o usuário avalie com até 5 estrelas uma proposta legislativa. |
| RF04 | O sistema deve permitir que o usuário visualize a lista de propostas legislativas, de forma ordenada. |
| RF05 | O sistema deve permitir que outros usuários curtam os comentários publicados. |
| RF06 | O sistema deve permitir que um vereador ou administrador da Câmara cadastre, edite e exclua propostas legislativas. |
| RF07 | O sistema deve permitir que o usuário pesquise propostas legislativas por palavra-chave. |
| RF08 | O sistema deve permitir que o usuário visualize o andamento da tramitação de uma proposta legislativa (ex: em análise, aprovada, rejeitada). |
| RF09 | O sistema deve permitir que o usuário visualize o resultado das votações de uma proposta legislativa (votos favoráveis e contrários). |
| RF10 | O sistema deve permitir que o usuário visualize um resumo da proposta legislativa em linguagem simples, sem jargão técnico ou jurídico. |
